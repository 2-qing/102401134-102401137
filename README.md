# 校园失物招领（Campus Lost &amp; Found）

> 2026 秋软件工程 · 结对编程作业（第二次）
> 结对成员：**102401134 王清源** &amp; **102401137 佘博海**
> 呈现形式：**PC 端 Web 网页**（纯前端，无需后端与数据库）

一个面向校园的失物招领平台：同学们可以发布**寻物启事**与**失物招领**信息，集中浏览全部内容，
按物品名称、地点、描述等**关键词搜索**，进入**详情页**查看完整信息并**一键复制联系方式**，
物品找回 / 归还后由发布者把信息标记为**「已找到 / 已归还」**，从而减少重复询问和无效联系。

---

## 一、功能一览

| 功能 | 说明 |
| --- | --- |
| 浏览信息 | 首页以卡片形式展示全部信息，顶部实时统计总数 / 寻物 / 招领 / 已解决 |
| 发布寻物 | 失主填写物品名称、类别、丢失地点、日期、描述、联系方式、照片 |
| 发布招领 | 拾获者发布捡到的物品信息，等待失主认领 |
| 关键词搜索 | 在物品名称、类别、地点、描述、联系人中做不区分大小写的模糊匹配，命中处高亮 |
| 分类筛选 | 按「全部 / 寻物 / 招领」切换，并按物品类别、状态筛选，可按时间排序 |
| 查看详情 | 展示图片、名称、类型、地点、日期、描述、发布者及联系方式 |
| 联系发布者 | 一键复制微信 / QQ / 手机号到剪贴板 |
| 更新状态 | 发布者可将信息标记为「已找到 / 已归还」，也可恢复或删除 |
| 我的发布 | 汇总本机发布的信息，支持状态筛选、批量管理、导出 JSON |

**分层设计**：页面脚本（`app.js` 等）只负责 DOM 与交互，所有业务规则（校验、搜索、筛选、排序、
状态更新、统计）都收敛在 `js/core.js` 中。因此 `core.js` 不依赖浏览器环境，既能在网页里
`<script>` 引入，也能被 Node.js 直接 `require` 做单元测试。

## 三、使用说明（测试人员如何运行）

### 运行网页

1. 下载 / 克隆本项目全部文件到本地任意目录。
2. 使用 **Google Chrome** 浏览器直接打开项目根目录下的 `index.html`
   （双击即可，无需搭建服务器、无需安装任何依赖）。
3. 首次打开会自动写入 4 条示例数据，方便你立即体验搜索与筛选；这些数据保存在
   你本机浏览器的 localStorage 中，**不会影响其他同学**。

> 小提示：若浏览器对本地文件限制较严，也可在项目根目录执行
> `python -m http.server 8000`，再访问 `http://localhost:8000`。

### 体验核心流程（发布 → 浏览/搜索 → 详情 → 联系 → 更新状态）

1. **发布**：点击右上角「发布信息」→ 选择「我丢了东西 / 我捡到东西」→ 填写表单 → 发布成功。
2. **浏览 / 搜索**：回到首页，输入关键词（如「一卡通」「图书馆」）搜索，或用类别、状态、排序筛选。
3. **查看详情**：点击任意卡片进入详情页，查看完整信息与发布者。
4. **联系发布者**：点击「复制」把联系方式复制到剪贴板。
5. **更新状态**：在「我的发布」或详情页，把信息标记为「已找到 / 已归还」。

### 运行单元测试

**方式 A（推荐，可视化）**：用 Chrome 打开 `tests/test.html`，页面会显示 31 个用例的运行结果。

**方式 B（命令行）**：在项目根目录执行：

```bash
npm install     # 首次运行需安装 mocha / chai（联网）
npm test        # 运行全部单元测试
```

预期输出：`31 passing`。

> 说明：`tests/lib/` 已内置 mocha 与 chai 的浏览器构建，因此**方式 A 无需联网**。

## 四、附加特点

- **关键词高亮**：搜索命中的文字在卡片中以黄色高亮显示，一眼看到匹配位置。
- **多维筛选 + 排序**：支持按类型、物品类别、状态组合筛选，并可按发布时间排序。
- **一键复制联系方式**：详情页把微信号 / QQ / 手机号一键复制，免去手动记录的麻烦。
- **表单即时校验**：失焦即校验，手机号、QQ 号按格式自动校验，错误字段高亮并给出原因。
- **图片上传与预览**：最多 3 张照片，本地预览，可在详情页切换查看（数据仅存本机）。
- **「我的发布」免登录管理**：用本机记录识别自己发布的信息，无需注册登录即可管理状态。
- **数据导出**：在「我的发布」页可把自己发布的数据导出为 JSON 文件备份。
- **XSS 防护**：所有用户输入在渲染前统一转义，防止注入脚本。

## 五、技术说明

- 纯前端实现，**零第三方运行时依赖**：核心逻辑为原生 JavaScript，图标为内联 SVG。
- 数据持久化使用浏览器 `localStorage`，刷新页面不丢失。
- 单元测试使用 **Mocha + Chai**，测试对象为 `js/core.js` 中的纯函数。
