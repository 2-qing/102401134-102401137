## 三、解题思路描述与设计实现说明【20 分】

### 3.1 代码实现思路（文字描述）【5 分】

在第一次结对作业的原型基础上，我们采用**「分层 + 纯函数核心」**的思路：

1. **核心逻辑与界面分离**：把校验、搜索、筛选、排序、状态更新、统计等业务规则
   全部写进 `js/core.js`，这些函数是**纯函数**（输入决定输出，不依赖 DOM），
   既能在网页里用，也能被 Node.js 直接 `require` 做单元测试。
2. **存储层封装**：`js/store.js` 用 localStorage 做持久化，页面不直接碰存储。
3. **UI 层复用**：`js/ui.js` 封装导航、卡片渲染、Toast、图标、复制等通用组件。
4. **页面层**：每个页面一个脚本，只负责「取数据 → 调 core → 渲染」。

数据模型：

```
Item {
  id, type(lost|found), name, category, location, date,
  description, contactName, contactType, contact, images[],
  status(active|resolved), createdAt, updatedAt
}
```

### 3.3 重要代码片段及解释【5 分】

1. **组合查询 `queryItems`**：把「筛选 → 搜索 → 排序」串起来，页面只需调一次。
2. **表单校验 `validateItem`**：集中处理必填、长度、格式（手机号 / QQ 号）校验，
   返回「字段 → 错误信息」的映射，页面据此高亮字段。
3. **不可变更新 `updateStatus`**：用 `map` 生成新数组，不修改原数组，避免副作用。

## 四、附加特点设计与展示【10 分】

### 4.1 创意独到之处与意义【3 分】

- **关键词高亮**：搜索后命中的文字在卡片中高亮，用户一眼定位，体验更直观。
- **多维筛选 + 排序**：支持按「类型 / 类别 / 状态」组合筛选，解决信息量大时的浏览效率问题。
- **一键复制联系方式**：减少手动抄写微信号 / QQ / 手机号的麻烦，也降低抄错概率。
- **「我的发布」免登录管理**：用本机记录区分自己的信息，无需注册即可更新状态，符合校园轻量场景。

### 4.2 实现思路【3 分】

- 高亮：`core.highlight()` 先 `escapeHtml` 再对关键词做正则替换，包 `<mark>`，兼顾安全与效果。
- 筛选：`core.filterItems()` 接收 `{type, category, status}`，逐条件过滤。
- 复制：优先用 `navigator.clipboard`，降级到 `execCommand('copy')` 兼容旧浏览器。
- 我的发布：发布时把 id 记入 localStorage 的「mine」列表，页面据此过滤。
