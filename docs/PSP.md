## 时间分配说明

- **需求分析**：在第一次结对作业原型的基础上，重新确认 MVP 范围，明确「发布—浏览/搜索—详情—联系—更新状态」五步主流程，砍掉聊天、地图、后台管理等超纲功能。
- **具体设计**：把业务规则从页面中剥离，单独设计为纯函数模块 `core.js`，以便单元测试；同时确定 localStorage 数据模型与页面结构。
- **具体编码**：按功能分模块提交（core → store → ui → 各页面），每完成一个可运行功能提交一次。
- **测试**：以白盒为主设计 31 个用例，重点覆盖表单校验的边界值（长度上下界、格式校验）、搜索/筛选的组合条件与状态更新的不可变性。
- **报告**：撰写 README、单元测试说明与博客。
